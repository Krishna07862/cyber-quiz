# Cyber Quiz

A cybersecurity quiz project.

## How to Run
Install Termux from github or Playstore or App store (recommended from github)

### Install Termux packages

#```bash

pkg update && pkg upgrade -y
pkg install git python -y.

run: git clone https://github.com/Krishna07862/cyber-quiz.git
run: cd cyber-quiz
run: python quiz.py
  
enter username to see leader board and save

###Enjoy the quiz


**On Android:** If you don't have a Ctrl key visible in Termux, press `Volume Down + O` to save, then `Volume Down + X` to exit. You can also enable the extra-keys row in Termux.
