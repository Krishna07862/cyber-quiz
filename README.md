# Python & Cybersecurity Quiz

A beginner-friendly quiz game with 30 questions about
Python programming and cybersecurity.

## Features
- 30 multiple-choice questions
- Random question order
- Automatic scoring
- Final percentage and feedback
- Beginner-friendly topics

## Requirements
- Python 3
- Termux or another Python terminal

## How to Run
python quiz.py
